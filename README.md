# MB Mahodi Portfolio Samurai

A cinematic dark-fantasy portfolio experience centered around the fictional action RPG, Oni Ronin — a masterless demon samurai navigating a fractured feudal underworld.

This project combines a premium game-brand landing page, immersive motion design, curated worldbuilding, and a polished product showcase to present a high-end portfolio concept with a strong visual identity.

## Overview

Oni Ronin is presented as a dark fantasy action RPG with:

- a dramatic hero-first introduction
- a layered worldbuilding narrative
- feature storytelling and gameplay pillars
- contract-based service sections
- collectible edition pre-order layout
- immersive motion and atmospheric styling

The experience is built as a responsive single-page web app using React and Vite, with custom front-end interactions designed to feel premium and cinematic.

## Features

- Dark fantasy visual direction and immersive branding
- Animated hero experience with layered storytelling
- Interactive contract showcase and search experience
- Arsenal / feature carousel with media switching
- Responsive pre-order edition cards
- Scroll-driven UI and motion-rich composition
- Optimized asset loading for imagery and video content
- Modern front-end stack with Vite + React

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion / animation support
- Static media assets and custom UI styling

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### Production build

```bash
npm run build
```
